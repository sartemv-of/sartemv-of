## 🚀 Featured Projects

### ⚓ **[Titanic Survival Prediction](https://github.com/sartemv-of/Titanik_Survival)**
An end-to-end machine learning pipeline predicting passenger survival on the Titanic.
- **Tech Stack:** Python, Scikit-learn, Pandas, Matplotlib
- **Key Features:** Comprehensive EDA, feature engineering, multiple model comparison (Logistic Regression, SVM, Random Forest).

### 🤖 **[AI Telegram Assistant](https://github.com/sartemv-of/Telegram_AI_Bot)**
An intelligent chatbot with persistent memory, built for natural, context-aware conversations.
- **Tech Stack:** Python, Telegram Bot API, OpenRouter AI, SQLite
- **Key Features:** Full conversation history stored locally, personalized user contexts, asynchronous processing.

### 🎭 **[Face Mask Detector](https://github.com/sartemv-of/Face_Mask_Detector)**
A production-ready, real-time computer vision system for detecting face masks in images and video streams.
- **Tech Stack:** OpenCV, TensorFlow/Keras (MobileNetV2), Python
- **Key Features:** Real-time webcam processing, batch image analysis, modular architecture, configurable confidence thresholds.
